# Knowledge policy

## Current policy
This entire vault is fictional. Use it only to demonstrate knowledge reuse.
Keep confirmed decisions and their reasons in project notes. Label proposals and
unknowns. Preserve human annotations. Keep raw chats, credentials and media out.
Use only this demo scope; do not consult another vault for this exercise.
This vault is local only. The kit does not synchronize Git automatically.

## Saving
Search for an existing topic before creating one. Check its current hash before
editing, make a focused change, then verify the changed section once. Include
scope, asset_type, status, project and date in YAML; record conclusion, reason,
constraints and real sources. Never invent approvals, dates, citations or URLs.
The helper only reads; an authorized AI editor or a person makes note edits.
